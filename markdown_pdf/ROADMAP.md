# Markdown PDF 产品路线图

## 产品原则

保持轻量，只提供两个清晰动作：

1. **Markdown 转 PDF**：确定性排版，不需要模型 API。
2. **文章摘要**：独立页面，点击生成时才把正文发送到模型服务。

两个功能保留在同一个仓库和 Streamlit 应用中，但代码、依赖和隐私提示互相隔离。暂不增加账号、数据库、历史记录、多模型编排或复杂的 AI 格式润色。

## V1.0：Markdown 转 PDF（已完成）

- Desktop / Tablet / Mobile 三种固定阅读模式；
- 中英文长文、目录、链接、引用、列表、代码和简单表格；
- 长 URL 安全折行；
- 导出前兼容性检查与生成后页面边界检查；
- 三模式回归文稿和冒烟测试。

## V1.0.2：GPT Markdown 生成规范（已完成）

- 在页面中提供一个直接复制格式要求的按钮，不重复展示提示词正文；
- 明确标题层级、支持语法、图片和表格限制；
- 明确禁止整篇外层代码围栏和当前渲染器不支持的结构；
- GPT 生成结果继续通过现有导出前检查，不增加 AI 修复流程。

## V1.1：文章摘要（基础版已完成）

新增一个独立的 Streamlit 页面：

- 上传或粘贴 Markdown；
- 提供简短摘要、标准摘要、分章节摘要三种模式；
- 支持中文和英文输出；
- 结果可以复制、下载为 Markdown，或直接发送到 PDF 页面；
- 支持 Desktop / Tablet / Mobile 紧凑摘要 PDF；
- 支持 Tablet / Mobile 连续 PNG 长图；
- 首版只接入 DeepSeek，不建立复杂 Provider 框架；
- 未配置 API Key 时，PDF 页面继续完整可用。

摘要提示词要求保留重要数字、日期、名称、限制条件、因果关系和否定表达，并把待摘要文稿标记为不可信材料。输出使用中性、高信息密度的语言，禁止模板化套话，只允许当前渲染器稳定支持的 Markdown。首版限制单篇 30 万字符并直接生成结果，不加入分块、合并和任务队列。

部署后建议用中文、英文和双语长文各做一次真实 API 调用，确认当前账户、模型和额度正常。

## V1.2：输入与结果优先体验（已完成）

- 取消侧栏页面分类，改为窄屏也可见的顶部单一切换按钮；
- 为 Streamlit Cloud 固定工具栏保留顶部安全区域，并提供手机端紧凑编辑器、换行选项、44 px 触控按钮和两列结果指标；
- 上传文件后自动沿用原文件名，粘贴内容仍使用稳定默认名；
- 生成后的下载入口置顶，预览其次，编辑和重新生成收进下方折叠区；
- PDF 与长图下载入口同时保留在页面顶部和导出操作区，避免生成后寻找按钮；
- 应用默认使用固定 Light 主题，保持编辑、预览与下载界面的文字对比度；
- 摘要输入扩展到 Markdown、UTF-8 TXT 和普通文本型 PDF；
- 使用 `pypdf` 的布局提取模式，保留页序和分页标记；扫描版 PDF 明确提示先做 OCR；
- 移除重复的 API 同意复选框，点击生成本身即为本次调用授权；
- 摘要方式收敛为快速概览、核心摘要、分章节摘要，减少重复要点并固定结论位置；
- Tablet / Mobile 长图升级为 3× 输出，宽度分别为 1500 px 和 1227 px；
- 增加 PDF 导入单元测试和“生成 PDF → 再提取文字”的回归检查。

## V1.3：输入闭环与网页文章（已完成）

- 把粘贴文字、上传文件、文章网址收敛为一个原文来源控件，原文编辑器始终可见；
- 上传 PDF 后显示页数和字符数，同一文件可主动重新读取，编辑后明确提示重新生成；
- 支持公开网页和微信公众号正文提取，保留标题、来源、作者和时间等可用元数据；
- 网页读取限制为公开 HTTP(S) 地址与 5 MB，阻止本机、内网、带凭据网址和不安全跳转；
- 为三种摘要方式补充固定输出结构与适用场景，默认选择日常使用的核心摘要；
- 当前模式提示词可直接复制，提示词、隐私和导出选项使用渐进披露；
- 结果直接显示，复制、Markdown 下载和发送到 PDF 保持同一层级。

## V1.4：零基础讲解（已完成）

- 在三个压缩粒度之外增加独立的零基础讲解模式，面向第一次接触主题的读者；
- 参考 ELI5 的零背景、少量文字和直观图解原则，用短句、日常词和具体类比建立理解；
- 原文缺少必要背景时明确说明，不凭常识补写事实，不使用儿童化或居高临下的语气；
- 保持与其他摘要模式相同的语言、复制、Markdown、PDF、长图和发送到 PDF 能力。

## 密钥与隐私

- DeepSeek Key 只从 Streamlit Secrets 读取；
- `secrets.toml` 永远不提交到 Git；
- 页面不提供可回显的 Key 输入框；
- 生成按钮旁明确提示正文将发送到 DeepSeek，不增加重复确认步骤；
- 日志、缓存和下载文件不记录 API Key；
- PDF 转换始终不依赖 API。

## 暂不开发

- AI 格式润色和复杂 Diff 工作区；
- 多模型切换与 Provider 管理后台；
- 用户账户、云端文稿历史和知识库；
- 复杂公式、Mermaid 和学术排版。

只有在真实使用显示出明确需求后，再考虑将摘要拆成独立项目或增加上述功能。
